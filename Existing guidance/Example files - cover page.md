#  Extended producer responsibility for packaging: example files for packaging data 

If you need to submit packaging data under extended producer responsibility for packaging these example files shows how you must structure your data.

If you’re an organisation that supplies packaging to consumers and businesses in the UK, you may have to take action to comply with extended producer responsibility (EPR) for packaging.

You may need to collect and submit data about packaging you’ve supplied through the UK market, or any filled packaging you have imported, emptied and discarded in the UK.

[Find out if you need to collect and report your packaging data](https://www.gov.uk/guidance/packaging-waste-prepare-for-extended-producer-responsibility).

If you do have to report packaging data this example file shows how you must structure your data. 

There is guidance that explains [how to create your file for extended producer responsibility](/government/admin/publications/1463057). This covers:

* which columns you'll have to complete
* the codes you'll need to enter 

The tool for [generating a packaging data file](https://www.gov.uk/government/publications/extended-producer-responsibility-for-packaging-generate-a-packaging-data-file) can also help you. 

Use the guidance and the tool together with these examples to create your own CSV file.

There are four example files.

## Example file for large producer 2025 submissions

There is a new column for January to June 2025 data, 'ram_rag_rating'. This is for submitting recyclability assessment data. Find out more about the [recyclability assessment methodology](https://www.gov.uk/guidance/recycling-assessment-methodology-how-to-assess-your-packaging-waste).

## Example file for small producer 2025 submissions

Small producers do not have to include recyclability assessment data but should keep the column in their CSV, leaving it blank. 

## Example file for 2025 compliance scheme submissions

There is a new column for January to June 2025 data, 'ram_rag_rating'. This is for submitting recyclability assessment data. Find out more about the [recyclability assessment methodology](https://www.gov.uk/guidance/recycling-assessment-methodology-how-to-assess-your-packaging-waste).

## Example for 2023/2024 submissions

If you're submitting or resubmitting data from 2023 or 2024, include all the 2025 columns, but leave transitional_packaging_units and ram_rag_rating blank.
