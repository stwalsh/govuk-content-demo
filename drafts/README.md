# Drafts

Your working drafts go here.

## Naming convention

`[topic]-v[version].md`

Examples:
- `registration-deadlines-v1.md`
- `registration-deadlines-v2.md` (after incorporating feedback)
- `do-i-need-to-register-as-reprocessor.md`

## Preview

Run `npm start` from the root directory to preview drafts with GOV.UK styling at http://localhost:3000
